## Информация о выполнении:
** Задание 1 (основное):
*   Создание класса Car, в котором содержится 3 поля: марка, мощность и год выпуска
*   Создание CarRepository для хранения и получения списка машин. По заданию, список машин хранится только в памяти в течении работы программы
*   Реализован вывод списка машин с нумерацией
*   Реализовано добавление объекта класса Car с консоли: функция зациклена для удобства пользователя и поддерживаетмножественный ввод.
*   Реализовано добавление объекта класса Car с файла: добавлен тестовый файл car.json. Программа ищет файл по названию в ресурсах проекта (src/main/resources).
*   Для парсинга JSON-файла подключена библиотека Jackson, а работа с файлами вынесена в служебный класс FileManager, который читает ресурс через getResourceAsStream и десериализует его в List<Car> с помощью ObjectMapper
*   Добавлен метод getCarDescriptions(), который преобразует список объектов Car в список строк с описанием каждого объекта через .map().
