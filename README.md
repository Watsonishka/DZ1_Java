# DZ1 Java — Каталог автомобилей

Консольное Java-приложение для управления коллекцией автомобилей. Поддерживает добавление данных вручную и импорт из JSON-файлов, фильтрацию и сортировку записей.

## Функционал

- **Добавление автомобилей вручную** — ввод марки, мощности двигателя и года выпуска с проверкой корректности данных и подтверждением добавления.
- **Импорт из JSON** — загрузка списка автомобилей из файлов в `src/main/resources/json/`. Некорректные записи отбрасываются, перед добавлением можно просмотреть результат и подтвердить операцию.
- **Просмотр каталога** — вывод всех добавленных автомобилей.
- **Фильтрация**:
  - по названию модели или его части;
  - по минимальной мощности двигателя;
  - по году выпуска.
- **Сортировка**:
  - по названию модели;
  - по мощности двигателя;
  - по году выпуска;
  - по возрастанию и убыванию.
- **Выбор алгоритма сортировки** — пузырьковая сортировка (*Bubble Sort*) или сортировка вставками (*Insertion Sort*).

## Технологии

- Java
- Gradle
- Jackson — чтение JSON
- Java Collections API и Stream API

## Структура проекта

```text
src/
└── main/
    ├── java/
    │   └── org/example/
    │       ├── collection/  # Собственная коллекция MyArrayList<T>
    │       ├── helpers/     # Чтение JSON-файлов
    │       ├── model/       # Модель автомобиля, репозиторий,
    │       │                # валидация и форматирование
    │       ├── sort/        # Алгоритмы сортировки и интерфейс
    │       ├── ui/          # Консольное меню и ввод данных
    │       └── Main.java    # Точка входа
    └── resources/
        └── json/            # JSON-файлы с данными автомобилей
```

## Запуск

Откройте проект в IntelliJ IDEA и запустите класс `Main`.

Для импорта данных укажите имя JSON-файла, расположенного в `src/main/resources/json/`, например `car.json`.

## Валидация данных

- Марка автомобиля не должна быть пустой.
- Мощность двигателя должна быть конечным числом больше нуля.
- Год выпуска должен находиться в диапазоне от 1900 года до текущего года.
- При импорте JSON некорректные записи пропускаются.
