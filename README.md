# Итоговое домашнее задание (Резяпова Р.И. РИМ-160980к, УРФУ)

## Задание 1 (основное):
### 1. Сущность и модель данных
* Создан класс Car, содержащий три обязательных поля, а также необходимые геттеры, параметризованный и пустой конструкторы для корректной работы сериализации.

### 2. Управление данными и репозиторий
* Создан класс-репозиторий CarRepository для централизованного хранения и управления списком машин в оперативной памяти в течение всего сеанса работы приложения.
* Реализован метод форматирования getCarDescriptions(), преобразующий коллекцию объектов в читаемый текстовый вид с использованием Stream API (map()).

### 3. Интерактивный пользовательский ввод (ConsoleInput)
* Реализовано консольное добавление экземпляров класса через консоль с поддержкой цикла и множественного ввода.
* Предусмотрена «защита от дурака»: проверка на пустые строки при вводе марки, контроль корректности числовых значений, защита от отрицательной мощности и валидация четырехзначного года выпуска.
* Перед сохранением объектов в репозиторий программа запрашивает у пользователя подтверждение действия.

### 4. Работа с файлами и JSON (FileManager)
* Для десериализации данных в проект интегрирована библиотека Jackson.
* Реализовано добавление экземпляров класса из файла формата JSON. Там предусмотрен универсальный механизм загрузки, позволяющий указывать как абсолютные пути к файлам на диске, так и относительные имена файлов в корне проекта.

### 5. Бизнес-логика и обработка коллекций
* Реализован метод фильтрации данных по названию модели (с приведением к нижнему регистру для нечувствительности к регистру ввода) с использованием Stream API.
* Добавлена сортировка списка машин по названию модели в алфавитном порядке с использованием Stream API.
