# Итоговое домашнее задание

## Информация о задании

*   **Форма проверки:** задание с проверкой преподавателем.
*   **Цели задания:** проверить уровень освоения содержания дисциплины «Специализированные инструменты прикладного программирования» и закрепить навыки написания кода на Java.
*   **Правила приёма работы:**
    *   Прикрепите ссылку на выполненное задание в GitHub-репозитории или его аналоге.
    *   Код должен быть написан на языке Java с применением Stream API, декомпозирован на функции, методы и классы, логически структурирован.

**Задание считается не выполненным, если:**
*   ссылка на репозиторий с кодом не прикреплена, не содержит ответа на задание или по ссылке отсутствует доступ;
*   код выдаёт ошибку или даёт неправильный ответ.

## Описание задания

### Обратите внимание
Задание разделено на три уровня сложности: базовый и два дополнительных. Дополнительные уровни выполняются по желанию.

Допустимы следующие варианты выполнения задания:
*   только базовый уровень;
*   базовый уровень + уровень 2;
*   базовый уровень + уровень 3.

*Одновременное выполнение уровней 2 и 3 не требуется, но возможно.*

## Технические требования

*   **Java 17+** — основной язык программирования.
*   **Stream API** — для обработки коллекций данных.
*   **Коллекции Java Framework:** `List` или собственная реализация коллекции (для дополнительного уровня сложности).
*   **Обработка исключений** с использованием `try-catch` и `try-with-resources`.
*   Для хранения исходных данных допускается использование текстовых файлов формата **TXT** или **CSV**.
*   Проект должен быть структурирован с использованием классов и методов согласно принципам объектно-ориентированного программирования.
*   **GitHub** или аналогичный сервис контроля версий — для хранения и предоставления доступа к коду.

## Уровень 1. Базовый (выполнение обязательно)

Разработайте консольное Java-приложение для обработки коллекции объектов.

1.  Выберите предметную область и создайте класс минимум с тремя полями.
2.  Реализуйте консольное меню.
    *   Обеспечьте работу программы в цикле до выбора пользователем пункта «Выход»;
    *   Реализуйте возможность добавления объектов:
        *   вручную через консоль;
        *   из файла.
3.  Выполните валидацию вводимых данных.
4.  Обработайте исключения, возникающие при вводе данных и чтении файла.
    *   При работе с файлами используйте конструкцию `try-with-resources`.
5.  Храните объекты в коллекции `List`.
6.  Используйте **Stream API** для обработки данных:
    *   отфильтруйте объекты по одному условию;
    *   выполните хотя бы одно преобразование данных через `map()`;
    *   отсортируйте данные по одному полю;
    *   выведите результат в консоль.
7.  Разместите проект в GitHub.

## Уровень 2*. Собственная коллекция

**\*Повышенная сложность (выполнение по желанию)**

Дополнительно к базовому уровню реализуйте собственную коллекцию.

На выбор:
*   аналог `ArrayList`;
*   аналог `LinkedList`.

**Коллекция должна поддерживать операции:**
*   `add`;
*   `get`;
*   `remove`;
*   `size`.

*   Для аналога `ArrayList` необходимо реализовать автоматическое расширение внутреннего массива.
*   Для аналога `LinkedList` необходимо реализовать собственный узел (`Node`) и хранение элементов через ссылки.

**Используйте собственную коллекцию в программе вместо стандартной реализации Java и продемонстрируйте:**
*   добавление элементов;
*   получение элемента;
*   удаление элемента;
*   вывод содержимого коллекции.

## Уровень 3**. Собственные алгоритмы сортировки и полиморфизм

**\*\* Высокая сложность (выполнение по желанию)**

Дополнительно к базовому уровню:

2.  Предоставьте пользователю возможность выбора алгоритма сортировки.
3.  Используйте обобщения (**Generics**) в реализации алгоритмов.
4.  Использовать **полиморфизм**, чтобы:

    *   выбирать необходимую реализацию во время выполнения программы.
5.  Предоставьте пользователю возможность выбора направления сортировки:
    *   по возрастанию;
    *   по убыванию.

## Пример реализации консольного меню

*Использование данного шаблона не является обязательным и приведено исключительно в качестве примера.*

```java
Scanner scanner = new Scanner(System.in);
 
while (true) {
   System.out.println("""
           
           ===== МЕНЮ =====
            1. Добавить данные вручную
            2. Загрузить данные из файла
            3. Обработать данные
            0. Выход
            """);
 
    System.out.print("Выберите пункт меню: ");
 
    String input = scanner.nextLine();
 
    int command;
 
    try {
       command = Integer.parseInt(input);
    } catch (NumberFormatException e) {
       System.out.println("Ошибка: необходимо ввести число.");
       continue;
    }
 
    switch (command) {
       case 1 -> {
           System.out.println("Добавление данных вручную");
           // TODO
        }
 
       case 2 -> {
           System.out.println("Загрузка данных из файла");
           // TODO
        }
 
       case 3 -> {
           System.out.println("Обработка данных");
           // TODO
        }
 
        case 0 -> {
            System.out.println("Завершение работы программы…");
            return;
        }
 
        default -> System.out.println("Неизвестная команда.");
    }
}
